# M1-001 公开首页与精选提示词库首发体验

## 功能目标

交付 Prompt Hub 第一个可供个人使用和分享给朋友试用的公开内容闭环，让用户能从首页进入提示词库，搜索和筛选首批精选内容，在详情页学习拆解并复制提示词。

## 依赖

- `M0-001` 基础工程骨架已完成。
- `M0-002` Harness 治理已完成。
- 已确认规格：`docs/superpowers/specs/2026-05-21-prompt-hub-public-home-prompt-library-launch-design.zh-CN.md`。

## 范围

- 升级工具型首页，展示提示词库入口、精选分类和精选提示词预览。
- 交付 `/prompts` 列表页，支持关键词搜索、分类筛选和标签筛选。
- 交付 `/prompts/[slug]` 详情学习页，展示正文、示例、结构拆解、优化对比、改进说明和相关提示词。
- 准备首批 20 条经过 review 的提示词 seed 内容，并按 v0.1 分类分布导入。
- 公开页面只读取已发布提示词。
- 为提示词正文提供复制反馈。
- 记录有效详情浏览次数和正文复制次数。
- 为内容、公开查询、统计、页面状态和浏览器检查提供验证证据。

## 不做范围

- 不实现 `/generator` 的真实 AI 文本生成。
- 不实现 `/image-to-prompt` 的真实图片上传和视觉分析。
- 不实现 `/learn` 的完整教程内容。
- 不实现管理员 CRUD、内容发布界面或后台统计面板。
- 不实现普通用户账号、收藏、评论、评分、付费和社区发布。
- 不实现全文搜索引擎、向量搜索、复杂排序控件或复杂推荐。
- 不实现独立访客分析、趋势报表、埋点平台或反作弊系统。

## 验收标准

- 首页能把公开用户引导到真实可用的提示词库体验。
- `/prompts` 能浏览首批 20 条公开提示词，并支持关键词搜索、分类筛选和标签筛选组合使用。
- `/prompts/[slug]` 能展示完整学习拆解内容并提供相关提示词入口。
- 公开页面不展示未发布或归档内容。
- 用户能复制提示词正文，并收到中文复制反馈。
- 有效详情浏览会记录浏览次数，正文复制会记录复制次数。
- 统计失败不会阻塞公开阅读和复制主流程。
- 页面具备列表无结果、公开内容为空、详情未找到等必要状态。
- 完成前已记录桌面端和移动端浏览器检查范围。

## 验证方式

- 新增或更新 seed、公开查询、统计和页面相关测试。
- 运行任务级相关测试与 `npm run typecheck`。
- 重要 UI 改动运行 `npm run lint` 并做浏览器检查。
- 最终运行 `npm run verify`。
